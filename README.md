# Trabajo Práctico: Regresión Lineal

Este repositorio contiene el desarrollo del Trabajo Práctico de Aprendizaje Automático, enfocado en la implementación y análisis de un modelo de regresión lineal.

## Descripción

El objetivo principal de este trabajo es aplicar técnicas de regresión lineal para resolver un problema específico, utilizando herramientas de análisis de datos y visualización. Se incluyen pasos para la preparación de datos, entrenamiento del modelo y evaluación de resultados.

## Configuración del Entorno

Antes de instalar las librerías necesarias, se recomienda crear un entorno virtual para aislar las dependencias del proyecto. Siga los pasos a continuación:

### Creación del Entorno Virtual

1. Asegúrese de tener Python instalado en su sistema.
2. Cree un entorno virtual ejecutando el siguiente comando:

    ```bash
    python -m venv nombre_del_entorno
    ```

3. Active el entorno virtual:
    - En Windows:
      ```bash
      nombre_del_entorno\Scripts\activate
      ```
    - En macOS/Linux:
      ```bash
      source nombre_del_entorno/bin/activate
      ```

4. Una vez activado el entorno virtual, puede proceder con la instalación de las librerías.

## Instalación de Librerías

Para ejecutar el código de este proyecto, es necesario instalar las siguientes librerías de Python:

- `numpy`: Para operaciones matemáticas y manejo de arrays.
- `pandas`: Para manipulación y análisis de datos.
- `matplotlib`: Para la generación de gráficos.
- `seaborn`: Para visualización de datos avanzada.
- `holidays`: Para trabajar con días festivos.
- `sklearn`: Para implementar y evaluar el modelo de regresión lineal.

### Instalación

Ejecute el siguiente comando para instalar todas las librerías necesarias:

```bash
pip install numpy pandas matplotlib seaborn holidays scikit-learn
```

## Uso

1. Clone este repositorio en su máquina local.
2. Cree y active un entorno virtual siguiendo las instrucciones anteriores.
3. Instale las librerías necesarias utilizando el comando proporcionado.
4. Ejecute el script principal para entrenar y evaluar el modelo de regresión lineal.
